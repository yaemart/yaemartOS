## 法务审阅要点（各品牌共同）

请法务重点确认以下条款：

1. **数据控制者信息**：公司法人实体名称、注册地址、联系邮箱是否准确
2. **数据收集范围**：§2 收集数据类型与实际系统功能是否一致
3. **法律依据（GDPR Art. 6）**：每项数据处理活动的法律依据是否充分
4. **数据保留期限**：§5 保留期限是否符合各市场要求
5. **Cookie 政策**：§7 Cookie 分类与实际使用是否一致
6. **未成年人保护**：§9 年龄限制条款是否满足各市场要求（COPPA/GDPR）
7. **第三方共享**：§4 第三方列表是否完整（支付、物流、AI 服务商）
8. **跨境传输**：§6 数据跨境机制（SCCs/Adequacy Decision）是否合规
9. **用户权利**：§3 权利行使流程是否与技术实现一致（DSR 响应时限）
10. **更新通知机制**：§11 变更通知方式是否符合监管要求

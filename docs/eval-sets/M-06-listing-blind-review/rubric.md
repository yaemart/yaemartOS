# M-06 Listing 盲审评分标准

> 版本：v1.0 | 适用：Amazon 英语 listing（S1 基线）  
> 评分者：运营人员（与 AI 生成过程无关），每切片末组织 1 次。  
> 通过标准：5 名运营盲审平均分 **≥ 3.5 / 5.0**。

---

## 评分维度与权重

| 维度               | 权重 | 说明                                             |
| ------------------ | ---- | ------------------------------------------------ |
| **信息准确性**     | 30%  | 产品属性、功能描述是否与实际产品一致，无虚假信息 |
| **关键词覆盖**     | 25%  | 核心关键词自然融入，不强行堆砌，符合 Amazon SEO  |
| **用户价值清晰度** | 20%  | 卖点是否站在买家角度，能清楚回答"为什么买这个"   |
| **语言自然度**     | 15%  | 英语表达地道，无明显机翻痕迹，符合品牌语气       |
| **格式规范性**     | 10%  | 字符数、大小写、标点符合 Amazon 要求             |

---

## 5 分制打分说明

### 1 分（不可用）

- 事实严重错误（容量/瓦数/材质错误）
- 严重语法错误，读不通
- 完全与产品无关的内容
- 字符严重超限（title > 200、bullet > 500）

### 2 分（差）

- 存在可能误导买家的信息
- 关键词堆砌，读起来生硬
- 核心卖点缺失（如锅类 listing 未提容量/材质）
- 语言有明显翻译腔

### 3 分（及格）

- 信息基本准确，无重大错误
- 关键词覆盖 60-70%
- 卖点表述平淡，但不错误
- 语言通顺，无明显语法错误
- 格式基本符合要求

### 4 分（良好）

- 信息准确，卖点完整
- 关键词自然融入，SEO 友好
- 有清晰的利益点（"Why buy"答案明确）
- 语言流畅，品牌语气一致
- 格式完全规范

### 5 分（优秀）

- 在 4 分基础上：情感共鸣强，能激发购买欲
- 差异化卖点突出（vs 竞品）
- 关键词布局专业（title 前 5 词含核心词）
- 语言自然如母语写手
- A+ 模块与主 listing 高度协同

---

## 评分流程

1. **盲审规则**：评分者看到的是 listing 内容，不知道是 AI 生成还是运营手写
2. **每人独立打分**，不讨论，填入 `score-sheet.xlsx.template`
3. 5 人分数收齐后由 PM 计算加权平均分
4. 低分（< 3 分）条目写明 `reason`，供 AI 工程师迭代 prompt
5. 评测结果存入 `results/<YYYYMMDD>.json`

---

## 评分表字段

```
sample_id     评测样本 ID（对应 samples.csv）
brand         品牌
platform      平台
locale        语言
reviewer_id   评分者 ID（匿名化）
score_accuracy    信息准确性（1-5）
score_keywords    关键词覆盖（1-5）
score_value       用户价值（1-5）
score_language    语言自然度（1-5）
score_format      格式规范（1-5）
weighted_total    加权总分（自动计算）
reason            低分原因（< 3 分必填）
```

---

## 通过与失败处理

| 情形                  | 处理                                                |
| --------------------- | --------------------------------------------------- |
| 平均分 ≥ 3.5          | 记录结果，标注"PASSED"                              |
| 平均分 3.0-3.4        | 分析低分维度，AI 工程师 14 天内提出 prompt 改进方案 |
| 平均分 < 3.0          | P2 升级，tech lead + 运营 PM 评估是否暂停该功能上线 |
| 单维度连续 2 次 < 2.5 | 该维度单独立项改进，优先级高于新功能                |

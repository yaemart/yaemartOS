# yaemartOS Dashboard 首页 UI 设计

> 落地切片：S1 W4（前端 shell + Dashboard 骨架）；指标卡数据 W4 展示占位，W7+ 接入真实领星数据  
> 对标：Stripe Dashboard（指标卡密度 + 数据可视化）+ Linear（近期活动流）  
> 关联指标：M-01 / M-02 / M-10（S1 可采集）；M-04 / M-05（S4 接入）  
> 关联审计：P0-8（数据展示权限隔离，运营只看自己 brand/shop 范围）

---

## 2. 指标卡（Metric Cards）

### 2.1 卡片规格

```
┌──────────────────────────────┐
│ 🟢  Listing 生成延迟   （?）  │  ← 图标 + 标题 + tooltip 帮助
│                              │
│  8.4s                        │  ← 主数值（大字号）
│  P95  ·  过去 24h            │  ← 数值说明
│                              │
│  ↓ 较昨日 12%     M-02 ✓    │  ← 趋势 + 指标编号
└──────────────────────────────┘
```

| 元素              | 规格                                                                 |
| ----------------- | -------------------------------------------------------------------- |
| 卡片容器          | `bg-white rounded-xl border border-zinc-200 p-5 flex flex-col gap-3` |
| 状态图标          | `w-2 h-2 rounded-full`（绿/黄/红 dot）                               |
| 标题              | `text-sm font-medium text-zinc-600`                                  |
| 主数值            | `text-3xl font-bold text-zinc-900`                                   |
| 数值说明          | `text-xs text-zinc-400`                                              |
| 趋势 - 上升（好） | `text-emerald-600 text-xs` + `↑` 图标                                |
| 趋势 - 下降（好） | `text-emerald-600 text-xs` + `↓` 图标                                |
| 趋势 - 劣化       | `text-red-500 text-xs`                                               |
| 指标编号 badge    | `text-xs bg-zinc-100 text-zinc-500 px-1.5 py-0.5 rounded`            |

**注意**：趋势方向的"好坏"取决于指标含义——延迟降低是好事（↓ 绿色），待审核数量降低也是好事（↓ 绿色）。

### 2.2 S1 可用指标卡（4 张）

| 编号 | 卡片标题       | 数值说明                | 数据来源           | S1 展示形式                   |
| ---- | -------------- | ----------------------- | ------------------ | ----------------------------- |
| M-01 | 系统在线状态   | P99 响应时间 / 错误率   | Sentry Performance | 实时（30s 轮询）              |
| M-02 | AI 生成延迟    | P95 端到端，过去 24h    | Sentry trace + DB  | 实时                          |
| C-01 | 待审核 Listing | 当前 review 状态数量    | PostgreSQL 查询    | 实时（60s 轮询）              |
| C-02 | 今日同步状态   | 领星 → 本地最后同步时间 | ShopBinding 表     | W7+ 接入真实，W4 显示"未配置" |

### 2.3 S4+ 扩展指标卡（接入后追加）

| 编号 | 卡片标题     | 数值说明             | 数据来源          |
| ---- | ------------ | -------------------- | ----------------- |
| M-04 | 库存同步误差 | 最近对账批次误差条数 | cron 对账结果     |
| M-05 | 广告花费偏差 | 最近 24h vs 领星原始 | cron 对账结果     |
| C-03 | 本月 AI 费用 | USD，按品牌分摊      | AiCallLog 聚合    |
| C-04 | 活跃用户     | 本周登录人数 / 38    | User session 统计 |

### 2.4 占位卡（数据未接入时）

当数据源未配置时，卡片显示占位态：

```
┌──────────────────────────────┐
│ 🔘  今日同步状态              │
│                              │
│  ─ ─ ─                       │  ← dash 替代数值
│  领星连接未配置              │
│                              │
│  [前往配置 →]               │
└──────────────────────────────┘
```

容器加 `opacity-60`，禁止鼠标悬停趋势动画。

## 6. 时间范围选择器

Dashboard 右上角全局时间范围控件，影响所有指标卡和图表的数据范围。

| 选项             | 快捷键     |
| ---------------- | ---------- |
| 今日             | D          |
| 昨日             | —          |
| 近 7 日          | W          |
| 近 30 日         | M          |
| 本切片（S1/S2…） | —          |
| 自定义           | 日期选择器 |

时间范围变更后，所有数据卡片显示骨架屏，并行 refetch。

## 7. 数据刷新策略

| 数据区域         | 刷新频率                | 实现方式                           |
| ---------------- | ----------------------- | ---------------------------------- |
| 系统状态（M-01） | 30s 自动                | `SWR` revalidateOnFocus + interval |
| AI 延迟（M-02）  | 60s 自动                | `SWR` interval                     |
| 待审核数量       | 60s 自动                | `SWR` interval                     |
| 近期操作日志     | 30s 自动                | `SWR` interval                     |
| 图表数据         | 手动刷新 / 时间范围变更 | 用户触发                           |
| 快捷操作待办     | 60s 自动                | `SWR` interval                     |

手动刷新按钮（右上角）点击后，所有区域同时触发 `mutate()`，按钮显示 `animate-spin` 1.5s。

## 8. 欢迎语逻辑

Page Header 欢迎语根据北京时间计算：

| 时段        | 文案                          |
| ----------- | ----------------------------- |
| 06:00–12:00 | 早上好，{name} 👋             |
| 12:00–18:00 | 下午好，{name} ☀️             |
| 18:00–22:00 | 晚上好，{name} 🌙             |
| 22:00–06:00 | 还在工作？{name}，注意休息 💪 |

大名显示用户姓名（User.name），匿名/加载中显示空（不显示占位符）。

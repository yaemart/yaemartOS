# yaemartOS 产品中心 UI 设计

> 落地切片：S1 W5（品类库）+ S1 W6（产品创建/编辑/列表）  
> 对标：Shopify Product Admin（表单密度）+ Notion（可折叠分区）+ Linear（列表筛选）  
> 关联 ERD：`docs/erd/domain-model.md` — Category / CategoryContentTemplate / Product / Article  
> 关联审计：M-07（产品导入准确率 ≥95%）/ P0-2（品类继承字段 source 标记）

---

## 1. 页面地图

```
/products                  ← 产品列表页
/products/new              ← 新建产品表单
/products/[id]             ← 产品详情（Tab 布局）
/products/[id]/edit        ← 编辑产品基本信息

/categories                ← 品类列表页
/categories/new            ← 新建品类
/categories/[id]           ← 品类详情（Tab 布局）
/categories/[id]/template  ← 品类内容模板编辑
```

## 6. 品类继承 UI 流程

当运营新建产品并选定品类后，系统自动触发「品类继承」：

```
选定品类：厨电·慢炖锅
      ↓
自动拉取 CategoryContentTemplate
      ↓
规格参数字段：渲染 spec_params 定义的输入控件，预填默认值
FAQ：渲染品类模板 FAQ（5 条），source = 'category_inherit'
菜谱：如 requires_recipe = true，渲染菜谱模板，source = 'category_inherit'
      ↓
运营可覆盖任意字段（覆盖后对应字段 source 变为 'manual'）
      ↓
保存：product_content 入库，source 字段准确记录
```

**视觉提示**：继承来的字段右侧显示 `[来自品类模板]` 蓝色文字标签；运营修改后标签变为 `[已修改]` 琥珀色。一键恢复按钮（`↺ 恢复品类默认`）显示在字段末尾，允许放弃修改回到继承值。

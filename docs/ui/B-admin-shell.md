# yaemartOS 管理后台 Shell UI 设计

> 落地切片：S1 W4（前端 shell + 路由 + 权限守卫）  
> 技术栈：Next.js 14 App Router + Tailwind CSS + shadcn/ui + Framer Motion  
> 对标：Linear（侧边栏密度 + 折叠）+ Stripe Dashboard（顶部 topbar + 面包屑）+ Vercel Dashboard（品牌区域）  
> 关联审计：P0-6（403 处理）/ P0-7（路由权限守卫）

## 3. Sidebar 导航结构

### 3.1 品牌上下文区（顶部固定，始终可见）

```
┌──────────────────────────┐

### 3.2 导航分组与项目

```
── 概览 ──────────────────────
  🏠 仪表盘           /dashboard
  📊 数据分析          /analytics      (S2 起)

── 商品运营 ─────────────────
  📦 产品管理          /products
  📝 Listing 管理      /listings
  🏷️  品类库           /categories

── 店铺运营 ─────────────────
  🏪 店铺绑定          /shops
  🔄 领星同步          /lingxing       (W7+)
  📋 库存监控          /inventory      (S2+)

── 客服 ─────────────────────
  💬 工单管理          /tickets        (S3+)
  🤖 AI 聊天配置       /chat-config    (S3+)

**访问控制**：路由权限与 Casbin IAM 联通。无权限的导航项隐藏（不显示灰色禁用态，直接不渲染）。

### 3.3 导航项样式规格

| 状态             | 样式                                                                       |
| ---------------- | -------------------------------------------------------------------------- |
| 默认             | `text-zinc-400 hover:text-zinc-100 hover:bg-zinc-800 rounded-md px-3 py-2` |
| 激活（当前路由） | `text-zinc-100 bg-zinc-800 rounded-md px-3 py-2 font-medium`               |
| 激活指示条       | 左侧 `w-0.5 bg-[--brand-primary]`（品牌色，4px 宽）                        |
| 分组标签         | `text-zinc-500 text-xs uppercase tracking-wide px-3 mb-1 mt-4`             |
| 图标             | Lucide，`w-4 h-4 mr-2.5 flex-shrink-0`                                     |

### 3.4 折叠态行为

- 折叠后宽度 **64px**，只显示图标（`w-5 h-5`，居中对齐）
- hover 图标时，在右侧 +8px 处显示浮动 tooltip（项目名称）
- `framer-motion` 控制宽度过渡：`duration: 0.2s, ease: easeInOut`
- 折叠态下分组标签不显示

### 3.5 底部固定区

## 4. 面包屑

面包屑位于 Topbar 中间区域（或内容区顶部，取决于页面深度）。

```
首页  /  产品管理  /  PRD-001
```

| 规格项         | 值                                                  |
| -------------- | --------------------------------------------------- |
| 分隔符         | `/` 或 `›`，`text-zinc-400`                         |
| 非末项         | 可点击，`text-zinc-500 hover:text-zinc-800 text-sm` |
| 末项（当前页） | 不可点击，`text-zinc-900 text-sm font-medium`       |
| 最大层级       | 4 层（超过折叠为 `首页 / … / 当前页`）              |

## 7. 响应式规则

| 断点                    | Sidebar                          | 主内容 |
| ----------------------- | -------------------------------- | ------ |
| `< 768px` (mobile)      | 默认隐藏，点击 `☰` 弹出 drawer  | 全宽   |
| `768px–1024px` (tablet) | 强制折叠态（64px），不可展开     | flex-1 |
| `≥ 1024px` (desktop)    | 默认展开（240px），可手动折叠    | flex-1 |
| `≥ 1280px` (wide)       | 展开，主内容区内边距 `px-8 py-8` | flex-1 |

移动端 Drawer 遮罩：`bg-black/40 backdrop-blur-sm`，点击遮罩关闭。

## 9. 权限守卫实现规范

```typescript
// app/(admin)/layout.tsx
// 该 layout 包裹所有 /dashboard /products /listings 等页面

async function AdminLayout({ children }) {
  const session = await getServerSession();
  if (!session) redirect('/login');

  // 品牌权限检查：从 URL 或 session 获取 brand scope
  // 无权则 render 403 组件，不 redirect（保留 URL 便于管理员排查）
}
```

**路由分组结构**：

```
app/
├── (public)/           ← 登录、注册、订单查询（无 layout 守卫）
│   ├── login/
│   └── order-lookup/
├── (admin)/            ← 管理后台（AdminLayout 守卫）
│   ├── layout.tsx      ← Sidebar + Topbar + 品牌守卫
│   ├── dashboard/
│   ├── products/
│   │   ├── page.tsx          ← 产品列表
│   │   └── [id]/page.tsx     ← 产品详情
│   ├── listings/
│   │   └── [id]/
│   │       ├── page.tsx
│   │       └── versions/[v]/page.tsx
│   ├── categories/
│   ├── shops/
│   └── settings/
└── (portal)/           ← 客户门户（各品牌独立 layout，S3+）
```
